## Overview

This proposal outlines growth strategies for **MoMo**, Vietnam's leading e-wallet, targeting user activation, viral gamification, and retention mechanics.

## Strategic Pillars

1. **Gamified Viral Loops**: Introducing referral bonuses coupled with interactive mini-games to boost peer-to-peer transaction volumes.
2. **Personalized Notifications**: Segmenting users based on transaction history and dispatching dynamic, behavior-triggered push notifications.
3. **Merchant Partnerships**: Designing targeted cashback rewards for daily essential services (groceries, transport) to cultivate sticky habits.

## Expected KPIs

- **User Activation**: +15% month-on-month active wallets.
- **Viral Referral Rate (K-factor)**: &gt;1.2.
